# 组件覆盖与迁移

## 覆盖规则

根入口完整覆盖 `@arco-design/web-vue` / `@arco-design/web-react` 全部组件及子组件，同时保留 `Arco` 命名空间以便直接调用原生 API。

## 补充组件清单

- **Vue 版补充**：`Surface`、`Header`、`Label`、`Description`、`FieldError`、`Fieldset`、`TextField`、`SearchField`、`InputOTP`、`Kbd`、`ListBox`、`ToggleButton`、`ToggleButtonGroup`、`Toolbar`、`TagGroup`、`ScrollShadow`、`ProgressBar`、`ProgressCircle`、`Meter`。
- **React 版补充 DSH 复合组件**：`PanelShell`、`SettingsCard`、`SettingsRow`、`MenuSelect`、`CodeBlockShell`、`JsonTree`、`FileTypeBadge`、`StatusLine`。
